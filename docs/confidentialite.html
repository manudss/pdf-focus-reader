Documents et lecture sur l'appareil

PDF Focus est un lecteur de fichiers PDF. Vous choisissez les fichiers accessibles par le sélecteur Android ou transmis à l'application. Le fournisseur de fichiers que vous utilisez peut être un service tiers ; ses propres règles s'appliquent à ce service.

L'application conserve une copie privée du dernier PDF dans son espace local pour permettre la reprise de lecture. Le document est analysé sur l'appareil pour détecter des zones et reconnaître du texte. Le PDF peut contenir des informations personnelles ; l'application les traite uniquement pour fournir les fonctions de lecture que vous demandez.

Le nom du document, son empreinte numérique, les cadres des blocs, leur ordre, la page, la position de lecture et certains choix de correction sont conservés localement. Le texte OCR est traité en mémoire ; les choix de correction enregistrés utilisent des empreintes et des identifiants plutôt que le texte reconnu.

Pas de transmission automatique

La version décrite ne demande aucune permission Internet. Elle n'envoie pas les PDF, le texte reconnu ni le parcours de lecture à l'éditeur. Elle ne comporte ni compte utilisateur, ni publicité, ni outil de mesure d'audience ou de suivi identifié dans l'audit. Les moteurs OCR sont embarqués et fonctionnent localement.

Partage à votre demande

Si vous utilisez « Partager l'article », l'application crée une image des blocs sélectionnés dans son cache local. Après votre action, le menu de partage Android vous permet de choisir l'application destinataire. Cette application reçoit l'image et applique ses propres conditions et règles de confidentialité. Ne partagez que les contenus que vous avez le droit de transmettre.

Conservation et suppression

La copie du dernier PDF reste sur l'appareil jusqu'à son remplacement ou sa suppression. Le menu « Supprimer le document local » supprime cette copie et le parcours enregistré, sans supprimer votre original. Cette commande ne garantit pas l'effacement de toutes les préférences ou de toutes les images de partage déjà créées. Les images temporaires de partage de plus de 24 heures sont nettoyées lors d'une nouvelle préparation de partage ; ce n'est pas une suppression planifiée à 24 heures.

Pour supprimer l'ensemble des données locales de l'application, utilisez les réglages Android : Applications → PDF Focus → Stockage → Effacer les données / le stockage, ou désinstallez l'application. Les images déjà partagées et vos PDF originaux restent sous votre contrôle dans les applications ou emplacements concernés.

Sécurité

Les fichiers de travail sont placés dans l'espace privé de l'application géré par Android. Le partage d'image accorde un accès en lecture au destinataire choisi par les mécanismes Android. La sauvegarde Android des données de l'application est désactivée dans sa configuration. Ces mesures ne constituent pas une garantie absolue de sécurité du téléphone ou des applications destinataires.
